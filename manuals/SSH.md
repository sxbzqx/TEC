## Как настроить автоматический запуск службы SSH в WSL на машине asu-10 при старте системы?

Чтобы служба SSH в WSL на asu-10 запускалась сама и не приводила к отвалам Docker после перезагрузки компьютера, нужно сделать две вещи: заставить wsl.conf поднимать systemd и включить автозапуск самой службы ssh.

Начиная с современных версий WSL2, это делается штатными средствами без костылей и скриптов в .bashrc.

## 1:
В ```/etc/wsl.conf``` добавить:


Или в WSL:

```Bash
sudo nano /etc/wsl.conf
```

прописать:

```
[boot]
systemd=true
```

## 2:

```sudo systemctl enable ssh```
